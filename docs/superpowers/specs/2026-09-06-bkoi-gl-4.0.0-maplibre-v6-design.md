# bkoi-gl 4.0.0 — maplibre-gl v6 migration + real-rendering test suite

Date: 2026-09-06
Status: Approved design

## Goals

1. Migrate bundled `maplibre-gl` from `^5.13.0` to exact `6.6.0` (matching react-bkoi-gl).
2. Bump package version to `4.0.0` (major).
3. Replace the Jest/jsdom fake-DOM suite with the react-bkoi-gl testing pattern:
   vitest (unit + browser), playwright e2e, framework compatibility matrix,
   package-manager resolution tests, pack verification.
4. Keep rollup as the bundler; keep maplibre-gl bundled as a regular dependency
   (NOT a peer); keep ESM/CJS/UMD/IIFE outputs so script-tag usage still works.

## Non-goals

- No build-tooling rewrite (no tsup migration).
- No peer-dependency switch; no changes to the public export surface beyond
  what maplibre v6 requires.
- No CI addition — existing `release.yml` stays as-is.

## Migration work (maplibre v5 → v6)

- Pin `maplibre-gl: 6.6.0` in dependencies; keep `maplibre-gl-draw: ^1.6.9`
  unless incompatible with v6 (then bump minimally).
- Audit and fix compile errors in `src/` (index.ts, controls/Minimap.ts,
  controls/ToggleButton.ts, utils/*) surfaced by `tsc --noEmit`.
- Verify `.maplibregl-*` DOM class references (attribution, logo) against v6
  markup.
- Verify rollup bundles v6 correctly (worker/asset handling may differ from
  v5) and all four formats still build.

## Test architecture

Mirrors react-bkoi-gl, adapted for a vanilla framework-agnostic library.

### Vitest (replaces Jest)

- `unit` project: pure logic — config, validator, utils, constants.
- `browser` project: real map rendering against Barikoi tiles with real-DOM
  assertions for: minimap, style drawer, navigation, geolocate, fullscreen,
  attribution, scale, polygon drawing.
- Existing Jest tests under `test/` are deleted, not ported.

### Playwright e2e

- Fixture-based specs exercising the **built dist** (ESM app + UMD
  script-tag page at minimum) in a served Vite app.
- Review/report tooling ported from react-bkoi-gl (`e2e:review`).

### Framework matrix (`tests/framework/run.mjs` port)

Per app: install deps with chosen PM, install packed tarball, build, serve,
headlessly verify map renders. Apps (one per framework, no version-spread
variants initially):

- React (Vite) — raw `bkoi-gl`, not react-bkoi-gl
- Vue 3 (Vite)
- Nuxt
- Angular (latest)
- Svelte 5 (Vite)
- SvelteKit

Flags: `--only=react,vue,nuxt,angular,svelte,sveltekit`, `--pm=npm|pnpm|yarn|bun`.

### Resolution test (`scripts/test-resolution.mjs` port)

Per PM (npm, pnpm, yarn, bun), in an isolated temp sandbox: minimal
package.json, install tarball, import `bkoi-gl` by name, resolve the
`./style.css` subpath to a real file. No app build or map render.

### Pack test (`scripts/test-pack.mjs` port)

`npm pack` content verification: dist formats, style.css, README, LICENSE.

### API key

`BARIKOI_API_KEY` env var, same `loadEnvKey` approach as react-bkoi-gl.

## Package changes

New scripts: `test`, `test:unit`, `test:browser`, `playwright:install`,
`e2e`, `e2e:serve`, `e2e:review`, `test:framework`, `test:framework:review`,
`test:resolution`, `test:pack`, `coverage`.

Removed devDeps: jest, jest-environment-jsdom, ts-jest, babel-*,
regenerator-runtime, @types/jest.
Added devDeps: vitest, @vitest/browser, playwright (+ chromium).

CHANGELOG updated for 4.0.0. Version bumped to 4.0.0.
